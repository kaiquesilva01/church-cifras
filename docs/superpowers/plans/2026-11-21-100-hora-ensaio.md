## Global Constraints

- Janela do ensaio (Rules): `rehearsalAt` (Timestamp) de 00:00 de 7 dias antes da `date` do culto até 00:00 do dia seguinte (exclusivo), em UTC-3 (America/Sao_Paulo, sem horário de verão). Em dias: o dia do ensaio fica em `[culto - 7, culto]`, inclusive.
- `rehearsalAt: null` é negado pelas Rules. Limpar a hora é `deleteField()` num `updateDoc`. Omitir o campo num update NÃO apaga.
- `origin` (`producao` | `teste`): criar (nova e duplicar) grava pelo host. `teste` só quando o host é exatamente `louvor-hajaluz-teste.web.app` (mesmo host de `SITE_BASE.teste` em `apps/functions/src/push/token.ts`); o resto, inclusive `localhost`, é `producao`. Editar não muda `origin`.
- Duplicar não copia `rehearsalAt`. `expiresAt` e o TTL não mudam.
- Textos de UI (pt-BR, exatos): "Hora do ensaio (opcional)", "Dia", "Hora", "Quem ativou os avisos é lembrado 30 min antes e na hora.", "Editar data, rótulo e ensaio", "Ensaio hoje às 18h30", "Ensaio amanhã às 18h30", "Ensaio dom · 22/11 às 18h30". Formato fora de hoje/amanhã: `Ensaio <dia da semana abreviado> · dd/mm às HHhMM`.
- Desvio do brief, decidido aqui: o exemplo "Ensaio sáb · 22/11" tem dia da semana errado, porque 22/11/2026 é domingo (o código já tem o teste `defaultLabel('2026-11-22') === 'Domingo'`). O código calcula o dia da semana; o texto sai "dom · 22/11".

```ts
import { shiftDate, todayLocal } from './dates';

/** O ensaio pode cair até 7 dias antes do culto (Rules: `validRehearsal`). */
export const REHEARSAL_DAYS_BEFORE = 7;
/** Brasília é UTC-3 o ano todo (sem horário de verão). */
const BRASILIA_HOURS = 3;
const WEEKDAYS_SHORT = ['dom', 'seg', 'ter', 'qua', 'qui', 'sex', 'sáb'];

export function isValidHour(hour: string): boolean {
  return /^([01]\d|2[0-3]):[0-5]\d$/.test(hour);
}

/** Dia (YYYY-MM-DD) e hora (HH:MM) em Brasília → instante. */
export function rehearsalInstant(day: string, hour: string): Date {
  const [y, m, d] = day.split('-').map(Number) as [number, number, number];
  const [h, min] = hour.split(':').map(Number) as [number, number];
  return new Date(Date.UTC(y, m - 1, d, h + BRASILIA_HOURS, min));
}

/** Instante → dia e hora em Brasília (inverso de `rehearsalInstant`). */
export function rehearsalParts(at: Date): { day: string; hour: string } {
  const local = new Date(at.getTime() - BRASILIA_HOURS * 3_600_000).toISOString();
  return { day: local.slice(0, 10), hour: local.slice(11, 16) };
}

/** Dias aceitos para o ensaio: de 7 dias antes do culto até o próprio culto, inclusive. */
export function rehearsalWindow(culto: string): { first: string; last: string } {
  return { first: shiftDate(culto, -REHEARSAL_DAYS_BEFORE), last: culto };
}

export function isRehearsalDayInWindow(day: string, culto: string): boolean {
  const { first, last } = rehearsalWindow(culto);
  return day >= first && day <= last;
}

/** Texto "Ensaio …" e se já passou (`past`), com "hoje"/"amanhã" pelo dia de Brasília de `now`. */
export function describeRehearsal(at: Date, now: Date): { text: string; past: boolean } {
  const { day, hour } = rehearsalParts(at);
  const today = todayLocal(now);
  let when: string;
  if (day === today) when = 'hoje';
  else if (day === shiftDate(today, 1)) when = 'amanhã';
  else {
    const weekday = WEEKDAYS_SHORT[new Date(`${day}T12:00:00Z`).getUTCDay()] as string;
    when = `${weekday} · ${day.slice(8, 10)}/${day.slice(5, 7)}`;
  }
  return { text: `Ensaio ${when} às ${hour.replace(':', 'h')}`, past: at.getTime() <= now.getTime() };
}
```

  );
